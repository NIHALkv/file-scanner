FILE SCANNER - Quick guide
==========================

WHAT IT DOES
Scans every drive on your computer and creates an Excel list of all your files:
File Name | Folder Path | Full Path | Type | Size (KB) | Last Modified

HOW TO USE
1. Double-click file_scanner.exe
   - If Windows says "Windows protected your PC": click More info -> Run anyway
2. Wait while it scans (usually 1-5 minutes). A black window shows progress.
3. The Excel file opens by itself and is saved on your Desktop as
   File_List_<date>_<time>.xlsx
4. Press Enter to close the black window.

PRIVACY
- Nothing leaves your computer. No internet is used.
- Only file names, sizes and dates are read, never what is inside the files.

WHAT IT SKIPS
Windows system folders (C:\Windows, ProgramData, AppData, Recycle Bin),
hidden folders, and folders Windows doesn't allow it to open.
